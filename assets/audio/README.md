# Audio narration files

Put your recorded narration MP3s in this folder, using these exact filenames:

- `home.mp3`
- `introduction.mp3`
- `movement-over-time.mp3`
- `temporal-methods.mp3`
- `action-quality.mp3`
- `research.mp3`
- `challenges.mp3`
- `conclusion.mp3`
- `bibliography.mp3`

The scripts are in `NARRATION_SCRIPTS.md` at the project root. Keep each file small (a mono MP3 at 64–96 kbps is plenty for speech) so pages load quickly.
